# Nothing in this application should ever appear in a search result.
#
# Not the app itself (it is one business's private jobs, prices and clients),
# not the sign-in page, and above all not the client-facing approval pages
# under /q/ — those are reached by an unguessable link that is texted to one
# person, and a search engine that indexed one would hand a client's prices
# to anyone who searched the right words.
#
# This file is the polite request. The X-Robots-Tag header set on every
# response in server.js is the part that does not rely on politeness, and the
# per-page <meta name="robots"> tags are the third layer for anything that
# reads the HTML but not the headers.
